# COMET TAIL — ルミと星の王冠

キツネの「ルミ」が主人公の横スクロール・アクション（HTML5 Canvas / ライブラリ不使用）。

## 起動

`game` フォルダで http-server を起動し、`http://localhost:8500/comet-tail/` を開く。
（Claude のプレビューなら launch.json の `comet-tail`）

- `?stage=1`〜`4` を付けるとそのステージから直接開始（テスト用）

## 操作

| 操作 | キー |
|---|---|
| いどう | ← → / A D |
| ジャンプ（2段・カベキック） | Z / Space / ↑ / W |
| ダッシュ（空中可・敵やレンガを破壊） | X / Shift |
| ヒップドロップ（空中で） | ↓ / S　※着地直後にジャンプで大ジャンプ |
| スターショット（パワーアップ中） | C / J |
| ポーズ / ミュート | P・Esc / M |

ゲームパッド対応（A=ジャンプ、X/RB=ダッシュ、B/Y=ショット）。

### スマホ・タブレット

タッチ端末では自動で画面上にボタンが出る（PCで試すときは `?touch=1`）。

- 左側：スティック（さわった場所が中心になる。左右でいどう、真下でヒップドロップ）
- 右側：ジャンプ／ダッシュ／▼ヒップドロップ／★ショット（同時押し可）
- 右上：ポーズ・ミュート・全画面（全画面は対応ブラウザのみ。Android では横向きに固定）
- メニューは画面タップで操作。縦向きでも遊べるが、横向きのほうが画面が大きい

公開URL: https://kiyohiro00.github.io/game/comet-tail/

## ステージ

1. そよかぜ草原 … 基本アクション、バネ、リフト、くずれ床、タル大砲
2. きらめき洞窟 … 暗闇ライティング、赤青スイッチ、ドッスン、コンベア、ダッシュクリスタル
3. ゆうやけ天空遺跡 … 上昇気流、タル大砲の連続、バネ渡り、雲リフト
4. マグマ城 … 溶岩、ファイアバー、砲台、ボス「マグマキング」

各ステージにスターコイン3枚。進行とベストスコアは localStorage に保存。

## 構成

- `js/util.js` 入力・効果音/BGM（WebAudio 合成）　`js/touch.js` タッチ操作
- `js/levels.js` ステージデータ（20マス幅チャンクのASCII。凡例はファイル冒頭）
- `js/world.js` タイル・当たり判定　`js/player.js` プレイヤー
- `js/entities.js` 敵・ギミック・アイテム　`js/boss.js` ボス
- `js/render.js` 背景・タイル・ライティング・HUD　`js/main.js` 進行管理
