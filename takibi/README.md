# 焚火 ― ただ、火を見つめる

夜の森で火をおこし、薪をくべ、息を吹いて火を守りながら、ただ焚火を見つめるゲーム。
得点も目標もありません。外部アセットは使わず、炎・薪・森・音のすべてをその場で計算・合成しています。

## 起動

`game` フォルダで http-server を立てて `/takibi/` を開く（`.claude/launch.json` の `takibi`、ポート 8610）。

```
node ./node_modules/http-server/bin/http-server . -p 8610 -c-1
→ http://localhost:8610/takibi/
```

## 遊び方

1. 火口（ほくち）を炉のまんなかに置く
2. 細枝を火口に立てかける（五、六本）
3. マッチを擦って火口に近づける
4. 細枝に火が回ったら、薪を二、三本寄り添わせてくべる
5. 弱くなったら薪を足す。熾（おき）が赤く残っていれば、薪をのせて息を吹くと再び燃え上がる

| 操作 | 内容 |
|---|---|
| 1 / 2 / 3 / 4 | 火口・細枝・薪・マッチ（手元の実物をクリックしてもよい） |
| クリック | 薪を置く ／ （火ばさみ）熾をつつく |
| ドラッグ（薪の上） | 火ばさみで薪をつかんで動かす |
| ホイール・Q / E | 持っている薪の向き・傾き |
| Space 長押し | カーソルのあたりへ息を吹く |
| ドラッグ | 見回す（見上げると星空）。手ぶらのホイールで火に寄る |
| 0・Esc・右クリック | 手を空ける |
| F・U・H | 全画面・表示を消す・手引き |

## しくみ

| ファイル | 役割 |
|---|---|
| `src/fluid.js` | 炎の流体シミュレーション（GPU）。速度・温度・可燃ガス・煙を解き、燃焼と浮力で炎の形とゆらぎを出す |
| `src/wood.js` | 薪の物理（太さのある棒の位置ベース力学）と燃焼モデル。1本を5節に分け、加熱→乾燥→熱分解→着火→炎→熾→崩落を節ごとに計算 |
| `src/logs.js` | 薪・細枝・火口・熾床の形とシェーダ（木目、樹皮、年輪、焦げ、亀甲割れ、赤熱、灰） |
| `src/scene.js` | 夜の森：地面、石の炉、木立、星空、月（実際の月齢）、手元の道具 |
| `src/post.js` | HDR → ブルーム → 陽炎 → 眼の順応・トーンマップ・粒状感 |
| `src/sparks.js` | 火の粉 |
| `src/hands.js` | 右腕・革手袋・火ばさみ（指の握り、2関節IKの腕、ばねで追う手首） |
| `src/audio.js` | 音の合成（炎の唸り・はためき、はぜる音の群れ、熾のちりちり、火ばさみ・薪・マッチ・息・衣擦れ、風、虫、フクロウ） |
| `src/main.js` | 描画ループ・操作・カメラ・UI |

燃焼モデルだけを机上で回すテスト： `node tools/simtest.mjs`

## しぐさ

- 薪・細枝・火口・マッチを手に取ると、体が火のほうへ身を乗り出す（`main.js` の `updateBody`）。手は画面の右下の外で持ち替えてから差し出し、置くときはそっと送り出して指を開く。
- 火ばさみは手ぶらのときに右手に持っている。薪の上でボタンを押すと手を伸ばし、先端が届いてから挟む（`tg.mode`: rest → reach → grip → linger）。動かさずにクリックすると熾をつつく。
- 息は「吸う → 細く長く吹く → 切れたら吸いなおす」（`updateBreath`）。吹くあいだは火の高さまで屈みこむ。
- 炎の明滅（`fl`）は明かりと音で同じ信号を使っているので、ゆらぎと唸りが揃う。

## 参考にした実物

`https://www.youtube.com/watch?v=jyN2jZL5gVg`（森の焚き火・2時間42分）の映像から、炎が細い舌に分かれること、太い薪が2〜3cm角の升目に炭化すること、熾が立体的な塊で奥から光ること、削り屑（フェザースティック）の火口と薄い木っ端の焚き付け、を取り入れた。音は聞けていないので、音は構造からの合成。

## 調整のつまみ

- 炎の高さ … `fluid.js` の `uBurn`（大きいほど短い）と `wood.js` `collectEmitters` の `fuel`
- 炎の明るさ・色 … `fluid.js` の `uGain` と `FIRE_FRAG` の色の段
- 燃え進む速さ … `wood.js` の `KV`（炎の時間）・`KC`（熾の時間）・`KM`（熾床の持ち）。手引き画面の「薪の燃える速さ」は `hearth.pace`
- 火の明かりの届き方 … `scene.js` の `fireLight` の decay（物理は 2。眼の順応ぶん 1.6 にしてある）

## 検証

Browser ペインが隠れていると rAF が止まるので、コンソールから `__dbg` を使う。

- `__dbg.start()` … タイトルを抜ける
- `__dbg.quick(3)` … 火口・細枝・薪3本を組んで燃えている状態にする
- `__dbg.sim(秒)` … 燃焼と物理だけを早送り
- `__dbg.step(コマ数)` … 描画込みで手動コマ送り
- `__dbg.ptr('pointerdown', nx, ny)` … 合成のポインタ操作（-1..1 の画面座標）。`__dbg.ndcOf(位置)` で薪の画面座標が取れる
- `node tools/shotserver.cjs` を立てて `await __dbg.shot('名前')` … canvas をそのまま `shots/` に保存（ペインの幅に左右されない）
